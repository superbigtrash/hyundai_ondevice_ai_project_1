## 2. 구매 검토 안건: 터치 디스플레이 vs 창고 모형

두 안은 서로 대체재가 아니므로 '둘 중 하나'로 묻지 말고 항목별 기준으로 평가한다. 'AI 토큰'은 의미를 먼저 정의한다 (예: LLM 사용료인지, 모형용 소품인지). 사용료라면 하드웨어 구매와 별도 안건으로 분리.

| 평가 기준 | 터치 디스플레이 | 창고 모형 (인형의 집 등) |
|---|---|---|
| 필수 범위(R01~R04) 기여 | 흐름도의 '보류: 미착용 항목 화면 표시'에 사용. 대안: LED·부저 + 노트북 대시보드 | 문 장치를 장착하는 구조물. 대안: 폼보드·골판지 시제품 |
| 비용 | 97,900원 | 견적 필요 (17,200원) |
| 구매 전에 정해야 할 것 | 화면에 보여줄 정보(Q24), 모델·전원·호환 | 문 크기·모터(Q25), 카메라 거리·각도(Q27) |
| 일정 위험 | 배송, 드라이버·해상도 설정 | 크기가 안 맞으면 재구매 |
| 시연 효과 | 판정 결과를 관객이 바로 확인 | 시연 몰입도, 설명 용이 |
| **평가 (팀 합의)** | **유지 및 실제 구현** | **추가 및 보호구 금액 축소 (확장으로 하되 우선도는 낮게)** |

판정 거리 기준(90~150cm 정지, 70cm 이내 안내)은 실제 사람 기준임. 모형은 사람이 들어가는 공간이 아니라 문 장치를 보여주는 소품이라는 점을 전제로 크기를 정한다.

결정 규칙 (제안):

- 필수 범위(R01~R04) 증거 계획에 기여하는 순서로 구매한다.
- 선행 결정(Q24, Q25, Q27)이 닫힌 항목부터 주문한다.
- 예산 상한을 넘기면 확장 항목부터 보류한다.
