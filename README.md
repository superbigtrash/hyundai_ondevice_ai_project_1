# Hyundai On-Device AI Project 1

## 프로젝트 목표

라즈베리파이 2대를 활용하여 **작업구역 출입 시 보호구 착용 여부를 확인하고, 현장 작업자의 보호구 착용 상태와 온습도를 지속적으로 모니터링하는 AI 안전관리 시스템**을 구현한다.

### 1. 출입구 보호구 확인 및 문 개방

첫 번째 라즈베리파이는 출입구에서 안전복과 안전모 착용 여부를 확인한다.

- 카메라 1대로 출입자의 안전복·안전모 착용 상태를 인식한다.
- **안전복과 안전모를 모두 착용한 것이 확인되면** 모터를 작동하여 모형 문을 연다.
- 보호구를 착용하지 않았거나 착용 여부를 확인할 수 없으면 문 개방을 보류한다.
- 보호구 착용 여부를 출입 조건으로 사용하며, 개인의 신원이나 출입 권한을 인증하는 기능은 별도로 구분한다.

### 2. 현장 보호구 착용 상태 모니터링

두 번째 라즈베리파이는 작업구역 내부의 보호구 착용 상태를 지속적으로 확인한다.

- 카메라 1대로 작업자의 안전복·안전모 착용 여부를 인식한다.
- 안전복 또는 안전모 미착용이 감지되면 경고를 표시한다.
- LED와 부저로 현장에 시각·청각 경보를 제공한다.
- 가림이나 영상 품질 문제로 판단하기 어려운 경우에는 ‘확인 불가’ 상태로 구분한다.

### 3. 온습도 이상 감지

두 번째 라즈베리파이에 온습도 센서 1개를 연결하여 작업 환경을 모니터링한다.

- 현장의 온도와 습도를 주기적으로 측정하고 표시한다.
- 측정값이 사전에 설정한 허용 범위를 벗어나면 이상 상태를 표시한다.
- 보호구 미착용과 온습도 이상을 구분하여 경고 원인을 확인할 수 있도록 한다.
- 온습도 허용 범위는 실습 환경과 운영 조건에 맞게 설정한다.

### 시스템 구성

| 구분 | 연결 장치 | 주요 기능 |
|---|---|---|
| 출입구 라즈베리파이 | 카메라 1대, 모터 | 보호구 착용 확인 및 모형 문 개방 |
| 현장 라즈베리파이 | 카메라 1대, 온습도 센서 1개, LED, 부저 | 보호구 착용 감시, 온습도 측정 및 이상 경보 |

### 구현 원칙

- PC에서 모델을 학습하고, 각 라즈베리파이에서 영상 추론을 수행하는 온디바이스 AI 구성을 목표로 한다.
- 영상 AI는 보호구 착용 상태를 판단하고, 온습도 이상은 센서 측정값과 설정 기준을 비교하여 판단한다.
- 일시적인 오인식으로 문이 열리거나 경보가 반복되지 않도록 연속된 인식 결과를 확인한다.
- 안전복·안전모의 착용이 확인된 경우에만 문 개방 명령을 내린다.
- 문 개방은 모형 장치로 시연하며, 실제 현장의 안전 인증이나 비상 대피 설계를 대체하지 않는다.

### 목표 시연 시나리오

1. 안전복과 안전모를 모두 착용한 사람이 출입구에 서면 모터가 작동하여 문이 열린다.
2. 안전복 또는 안전모를 착용하지 않은 경우 문이 열리지 않는다.
3. 작업구역 내부에서 보호구를 벗으면 미착용 경고와 LED·부저 경보가 발생한다.
4. 온도 또는 습도가 설정 범위를 벗어나면 해당 측정값과 이상 상태가 표시된다.
