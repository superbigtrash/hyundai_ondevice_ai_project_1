# 26.11.16 착수 회의

- 일시: 2026-11-16
- 안건: 프로젝트 목표, 시연 시나리오, SW/HW 구현 범위
- 참석: (기록 없음)

## 목표

라즈베리파이 2대와 카메라·센서로 두 가지를 구현한다. 출입구에서는 안전모·안전복 착용을 확인해 모형 출입문을 열고, 현장에서는 작업자의 보호구 착용과 환경, 화재 징후를 감시한다.

## 기존 방향 재확인

| 구분 | 기존 방향 | 회의 결과 |
|-|-|-|
| 적용 공간 | 물류 작업구역 축소 모형 | 카메라 감지를 확인한 뒤 구현 |
| 출입구 Pi | 카메라로 안전모·안전복 확인 후 모터로 바리케이드 개방 | 변경 없음 |
| 통과 확인 | 초음파 센서로 통과 확인 후 일정 시간 뒤 닫기 | 변경 없음 |
| 출입구 표시 | 정상·미착용 LED, 미착용이면 빨간 LED | 변경 없음 |
| 현장 Pi | 보호구 감시, LED·부저, 온습도 측정 | 온습도 측정은 카메라 감지를 확인한 뒤 구현 |
| 화재 감지 | 적외선 카메라 추가 | 열화상 카메라 MLX90640으로 변경 |
| 안전복 | 기존에 구매한 안전복은 붉은색 | 이 안전복은 일반 작업복으로 가정하고 진행 |

## 범위

필수는 이번 발표에서 반드시 구현하고, 확장은 필수를 끝낸 뒤 구현한다. 제외로 분류한 항목은 없다.

| ID | 기능 | 구분 | 완료 증거 |
|-|-|-|-|
| R01 | 안전모·안전복 착용 여부 구분 | 필수 | 네 가지 착용 조합 시험 결과 |
| R02 | 보호구 확인에 따른 바리케이드 개방 | 필수 | 개방·보류 동작 영상 |
| R03 | 통과 확인과 지연 닫힘 | 필수 | 통과·미통과·가림 시험 영상 |
| R04 | 현장 미착용 감지와 LED·부저 | 필수 | 경보 및 정상 복귀 기록 |
| R05 | 온습도 측정과 범위 이탈 표시 | 확장 | 정상·이상·센서 오류 기록 |
| R06 | 열화상 카메라를 이용한 화재 징후 표시 | 확장 | 입력 종류 및 검증 방법 명시 |
| R07 | 현장 인원 표시 | 확장 | 집계 정의 및 오차 측정 |
| R08 | 상태 화면과 이벤트 기록 | 확장 | 발생 시각·위치·원인을 보여 주는 화면 |
| R09 | 화재 징후와 바리케이드 제어 연동 | 확장 | 연동 정책·시험 결과. 정책이 정해지기 전에는 자동으로 적용하지 않음 |
