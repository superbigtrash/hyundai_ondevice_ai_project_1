## 📈 성능 비교

A - YOLO 모델 YOLOv8n, construction-ppe 데이터셋 테스트
B - Robbin 데이터셋으로 변경
C - head 이미지 3배 오버샘플링
D - 해상도 변경
E - 학습량 20 -> 50 EPOCHS

정확도는 **같은 test 사진 2,751장**으로 비교 (A는 construction-ppe 데이터 기준이라 직접 비교 불가)

| 단계 | 바꾸는 것 | mAP@0.5 | head recall | FPS (PC CPU) | FPS (Pi) |
|---|---|---|---|---|---|
| Yolo 모델 테스트 (A) | YOLOv8n, construction-ppe 12클래스, 320px | 0.633 | – | 114 | 측정 필요 |
| 데이터셋 교체 (B) | ppe3 3클래스, 원본 스크립트, 320px | 0.883 | 0.759 | 114 | 측정 필요 |

| 양자화 | INT8 | 미실시 | | | |

⭐ = 현재 적용 모델 (`best.pt`)


> - mAP@0.5: 세 가지(안전모·미착용·조끼)를 얼마나 정확히 찾는지 나타내는 종합 점수 1에 가까울수록 좋다.
> - head recall: 실제 안전모 미착용자 중 모델이 찾아낸 비율. 0.851이면 100명 중 약 85명을 찾아요.
> - FPS: 1280×720 화면으로 측정

### 💡 시사점
1. 미착용 사진을 늘려서 미착용자를 찾는 비율이 76% → 82%로 상승
2. 해상도 멀리 있는 머리는 작아서 작은 화면(320px)에서는 인식이 잘 안됨
3. 학습을 50번까지 늘리면 안전모·조끼는 더 잘 찾지만, 미착용 성능은 그대로임. 데이터 보강 필요
4. 파이캠 영상은 와이드(16:9)라서 화면 비율을 맞추면 35~45% 더 빨라짐
